# v1.2.5 Release Notes（存档）

## Highlights

- **Native context menu (right-click) now follows the system language** on macOS — previously always English.
- **Startup progress wording no longer looks like an error** on a healthy boot.

## Changes

### Fixed
- **Right-click menu / spell-check / native pickers were always English.** The app bundle declared no `CFBundleDevelopmentRegion` / `CFBundleAllowMixedLocalizations`, so WKWebView fell back to English regardless of the OS language. Both keys are now set in every build (local `tools/make-app.sh` and CI).
- **"启动尝试 1/6，失败详情见 logs/dsh-web.err.log" shown on every boot** — that message is a pre-attempt progress line, and mentioning failure logs before anything had failed made healthy startups look broken. Attempt 1 now reads "正在启动 DSH 后台服务…"; only actual retries (attempt ≥ 2) mention the error log.

## Install

| Platform | Asset |
|---|---|
| macOS (universal) | DSH-Desktop-macos-universal.dmg |
| Windows x64 | DSH-Desktop-Setup-x.y.z.exe |
| Linux x64 | DSH-Desktop-linux-x64.tar.gz |

### macOS
1. Download the DMG and open it.
2. Double-click **Install DSH Desktop.command**.
3. First launch asks **once** for removable-volume / disk access — click Allow.

### Windows
Run the Inno Setup installer.

### Linux
```bash
tar xzf DSH-Desktop-linux-x64.tar.gz && cd DSHDesktop && sudo ./install.sh
```
