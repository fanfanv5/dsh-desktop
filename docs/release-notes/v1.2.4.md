# v1.2.4 Release Notes（存档）

## Highlights

- **Fixed: app quit left dsh web running in the background on macOS.** Cmd+Q / dock Quit / logout never reached the cleanup path, orphaning the whole node process tree; now every quit path tears it down.

## Changes

### Fixed
- **Background processes survived app quit** (macOS). Root cause: tao maps Cmd+Q / dock Quit / logout to `Event::LoopDestroyed` (via NSApplication terminate), not to `WindowEvent::CloseRequested` — the cleanup only ran on the latter, so the dsh web watchdog tree (sh / node / npm / MCP servers) kept running as orphans. Cleanup now also runs on `LoopDestroyed`; the red close-button path is unchanged (belt and braces).
- Signing-identity script (`tools/make-signing-identity.sh`) now prints actionable guidance when the keychain key lacks codesign access (headless runs used to fail with `errSecInternalComponent` and no hint).

## Install

| Platform | Asset |
|---|---|
| macOS (universal) | DSH-Desktop-macos-universal.dmg |
| Windows x64 | DSH-Desktop-Setup-x.y.z.exe |
| Linux x64 | DSH-Desktop-linux-x64.tar.gz |

### macOS
1. Download the DMG and open it.
2. Double-click **Install DSH Desktop.command**.
3. First launch asks **once** for removable-volume / disk access — click Allow.

### Windows
Run the Inno Setup installer.

### Linux
```bash
tar xzf DSH-Desktop-linux-x64.tar.gz && cd DSHDesktop && sudo ./install.sh
```
